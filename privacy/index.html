Privacy notice

This notice explains what personal data this site processes and why. It follows the Swiss Federal Act on Data Protection (FADP).

Who is responsible

Gabriel Torres Gamez
Email: mail@torres.swiss

Hosting on GitHub Pages

This site is hosted on GitHub Pages, a service of GitHub, Inc. in the United States. When you open a page, your browser connects to GitHub's servers, and GitHub processes technical data about the request. GitHub states that it logs and stores the IP address of every visitor to a GitHub Pages site for security purposes. As with any web server, a request also carries the date and time, the page or file you asked for, the browser identification your browser sends (user agent) and the page you came from (referrer), if your browser sends them.

GitHub processes this data on its own responsibility. I have no access to these logs, I cannot see who visits this site, and I do not decide how long GitHub keeps them. Details are in the GitHub Privacy Statement.

Transfer abroad

Because the site is served by GitHub, the data above is processed outside Switzerland, including in the United States.

GitHub states in its privacy statement that it complies with the Swiss-U.S. Data Privacy Framework, and that it otherwise relies on the standard contractual clauses of the European Commission. Switzerland recognises US companies certified under that framework as offering an adequate level of data protection.

If you do not want your data processed in the United States, please do not use this site; you can reach me by email instead.

No cookies, tracking or other third parties

  • The site sets no cookies and uses no analytics, advertising or social media plugins.
  • All files (scripts, styles, fonts, images) come from the same address as the page. Pages load nothing from any other server.
  • The terminal runs in your browser. What you type into it is not sent anywhere.

Data stored in your browser

So that the boot sequence plays only once per visit, the site saves the value booted in your browser's session storage. It stays in your browser, is never sent to a server, and is deleted when you close the tab.

You can block site data for this site in your browser settings. The site still works, but the boot sequence may be skipped or shown again.

Content about me

The site shows my own CV: name, portrait, work history, education and certificates. It contains no personal data about other people.

Links to other websites

The site links to LinkedIn, GitHub, my blog and project pages. When you follow such a link, the privacy rules of that website apply. No data is sent to those sites before you click.

Your rights

You can ask which personal data about you I process, and ask me to correct or delete it. Write to the email address above. I do not store any data about visitors myself. For the logs GitHub keeps, please contact GitHub as described in its privacy statement.

You can also file a complaint with the Federal Data Protection and Information Commissioner (FDPIC).

Changes

I may update this notice when the site changes. The current version is always on this page.
